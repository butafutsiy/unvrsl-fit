# UNVRSL FIT · Anatomy Video Studio

## Цель
Анатомический персонаж в тёплой стилистике UNVRSL FIT (рельефные мышцы, натуральный оттенок тканей, чёрные шорты, светлый фон), предназначенный для научно-популярных роликов о биомеханике.

## Текущий прототип
- `anatomy.html`: собственный MakeHuman-манекен с условными интерактивными зонами мышц.
- `anatomy-studio.html`: отдельная анатомическая модель Écorché с настоящими раздельными мышечными объектами; кадр 9:16; 3/4, передний, боковой и задний ракурсы; выбор мышц, слои, экспорт PNG 1080×1920, запись поворота в поддерживаемом браузером видеоформате.
- Прототип загружает с внешнего источника `ecorche.meshopt.glb`. При недоступности сети или WebGL 3D не отобразится.
- Модель Écorché статична: скелет на основе человеческой анатомии не является анимационным ригом. Движения суставов и мышц пока отсутствуют.
- Шорты сделаны процедурной геометрией и не являются симуляцией ткани.
- Изменение цветов и материалов не превращает атлас в измерение мышечной активности.

## Как «натянуть» анатомию на наш манекен для видео
1. В Blender импортировать оригинальный `ecorche.glb` (НЕ meshopt-файл). Для Blender формат glTF подходит лучше.
2. Импортировать нашу MakeHuman-модель, полученную из `assets/3d/human.json`, в исходной T/neutral pose вместе с её скелетом.
3. Совместить высоту, таз, плечевые суставы, локти, колени, щиколотки и кисти. Начинать с единой нейтральной позы; не совмещать уже согнутую руку с прямой.
4. Подогнать внешний силуэт отдельных поверхностных мышц под MakeHuman **вручную или через cage / surface deform**. Простая проекция текстуры не даёт нужной геометрии: пересечения и просветы нужно устранять.
5. Перенести вершинные веса с MakeHuman на анатомические меши в Blender через Data Transfer → Vertex Groups → Nearest Face Interpolated. Проверить и вручную скорректировать веса вблизи плеча, лопатки, таза, локтя и колена.
6. Связать анатомические объекты с ригом через Armature Modifier. Сухожилия и глубокие мышечные структуры требуют отдельной настройки, нельзя автоматически считать их функционально верными после переноса весов.
7. Создать корректирующие shape keys / pose-space деформации для сокращений и крайних амплитуд; проверить особенно разгибание локтя для трицепса, сгибание плеча для широчайшей, разгибание бедра для ягодичных.
8. Перенести движения упражнений в Animation Actions, проверить отсутствие провалов геометрии и сохранить рабочий риг в Blender, затем экспортировать `.glb` для Three.js.
9. В студии добавить проигрыватель движения, паузу в верхней/нижней точке и синхронную подсветку выбранной мышцы по сценарию.
10. Для итоговых Reels рендерить 1080×1920 / 30–60 FPS. Маски подсветки должны сопровождать анатомические поверхности. Встроенная браузерная запись пока пригодна прежде всего для поворотов камеры и референсов, не заменяет финальный 3D-рендер.
