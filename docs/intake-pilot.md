# Анкета и черновик программы (v445)

## Сценарий

1. В «Клиенты +» выбрать ссылку регистрации, анкету программы или офлайн-клиента. Также в разделе «Программы» нажать «Отправить анкету» или открыть `intake.html`.
2. Клиент заполняет анкету без регистрации. Генерация работает в браузере без API.
3. Клиент видит предварительную программу на четыре недели и отправляет тренеру ссылку через меню «Поделиться» или копированием.
4. Тренер открывает ссылку, сохраняет черновик в редактор, проверяет все недели и нажимает «Анкета и утверждение».
5. После утверждения доступны запуск, сохранение шаблона и обычная отправка программы, включая существующее облачное назначение.

## Границы пилота

- Ссылку отправляет сам клиент. Облачного входящего списка и автоматического уведомления тренера в этой версии нет.
- Ссылка содержит закодированные (не зашифрованные) ответы в URL fragment. Она предназначена только для передачи своему тренеру. Она содержит имя, фамилию, параметры тела и сведения об ограничениях здоровья. Не публиковать открыто.
- Проверка локальная: отметка «утверждено» является рабочим состоянием редактора, а не серверной подписью личности тренера.
- Возраст 18–70 лет, 2–4 дня, 30–75 минут, два уровня опыта. Возраст вне пилота или заявленные ограничения передают анкету на ручной разбор без автоматического назначения упражнений.
- При нехватке оборудования для обязательного движения автоматический план не создаётся. В редакторе можно заполнить программу вручную.
- Упражнения выбираются из ограниченного проверяемого списка по ID основного каталога. Анкета учитывает исключения клиента.
- Алгоритм является стартовым шаблоном для проверки, не обещает оптимальности. Рабочие веса не выводятся из возраста или массы тела. Сохраняется существующая система рекомендаций после утверждения.
- Недельные настройки созданы отдельно от встроенного восьминедельного цикла. Автоматические проценты 1ПМ отключены; диапазоны повторов, RPE, темп и отдых сохраняются.
- Оценка времени включает 8 минут разминки и приближённую длительность подходов, отдыха и переходов. Если лимит не укладывается даже после сокращения дополнительных упражнений и подходов до двух, тренер получает предупреждение.
- Повторное открытие одной анкеты не создаёт дубликат локального черновика. Удалённый черновик можно восстановить из ссылки.
- При отправке утверждённой программы клиенту и сохранении шаблона анкета и ключ исходной ссылки удаляются из экспортируемой копии.

## Проверка

- `node --test tests/*.test.cjs`: общий набор, включая 48 комбинаций анкет, исключения, оборудование, ограничения и повреждённые ссылки.
- `node scripts/audit-exercises.cjs --strict`: каталог упражнений.
- `UNVRSL_JSDOM=<jsdom module> node tests/runtime-v392.cjs`: существующий сценарий тренировки.
- `UNVRSL_PLAYWRIGHT=<playwright module> UNVRSL_CHROMIUM=<browser executable> node tests/runtime-intake.cjs`: мобильная анкета, обмен ссылкой, редактор, сохранение после перезагрузки, отсутствие дублей, блокировка до утверждения и экспорт без анкеты. Внешние запросы заблокированы; модуль облачных программ загружается локально для проверки общих функций экспорта, реальные облачные записи не выполняются.

## Расширенная анкета v445

- Отдельные имя и фамилия, пол, возраст, рост и вес; общий спортивный и силовой опыт, виды спорта и перерыв.
- Группы оборудования: зал, собственный вес, турник и брусья, гири, штанга, гантели. Для домашних занятий уточняются скамья и стойки.
- Конкретные ограничения выбираются несколькими флажками, дополнительно уточняются боль, ограничения врача, отдел позвоночника и свободный комментарий. Наличие ограничения означает ручной разбор, а не медицинский запрет на все упражнения.
- КБЖУ рассчитываются тренером из сохранённой анкеты через существующий калькулятор питания. Используются текущие тренировки, шаги и активность, а не планируемый график. Личные настройки тренера не меняются. Неизвестные данные требуют уточнения; отдельные состояния передаются на индивидуальный разбор.
- Ссылки v1 продолжают открываться; для расчёта питания из старой анкеты нужны новые данные.
