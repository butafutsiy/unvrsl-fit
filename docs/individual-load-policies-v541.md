# v541: индивидуальные рекомендации без изменения задания

Восстановлены правила коррекции нагрузки для всех 189 упражнений каталога. Целевые RPE/RIR, повторы, темп, отдых и недельные параметры берутся из исходного плана. Сдвиг RPE из v540 полностью исключён из расчёта и редактора оборудования.

Фактический RPE/RIR сравнивается с заданным диапазоном. Коррекция зависит от упражнения, выбранного тренажёра, его доступного ряда или шага, границ веса и максимального числа ступеней. Недобор повторов с низким усилием не вызывает повышения. Без оценки усилия нагрузка сохраняется. RPE 0 считается отсутствующей оценкой, RIR 0 – предельным усилием.

Для стандартных подходов применяются индивидуальные проценты L1/L2/H1/H2/H3. Разминка, разгрузка, тест и специальные методы сохраняют свои обработчики. Назначенный тренером вес меняется только при явном принятии рекомендации. Автовес заполняет неназначенный вес с учётом имеющихся фактов. После выполнения подхода показывается отдельная рекомендация на следующий.

Недельный исходный расчёт отделён от коррекции следующего подхода. Проверка примера: e1RM 195,7, неделя 75–80%, цель RPE 7–8 → 152,5 кг с шагом 2,5 кг; назначенные 160 кг сохраняются до принятия.

Сохранённые в v540 сдвинутые цели исправляются только в незавершённой тренировке при наличии точной метки наследования, исходных границ и совпадения старого сдвига. Ручные цели и фактическая история сохраняются. Источники программ и шаблонов остаются идентичны v538.
