# UNVRSL FIT v1.1 stable

Зафиксированная стабильная копия актуального `main` от 31.08.2026. Интерфейс и функции совпадают с основным сайтом, а дальнейшие эксперименты в `main` не меняют эту версию автоматически.

В сборку входят оба режима приложения:

- клиент: назначенная программа, профиль и замеры, календарь, старт тренировки, анкета самочувствия, журнал, статистика и упражнения;
- тренер: клиенты, назначение и удаление программ, просмотр прогресса, редактор программ и шаблоны;
- методы UNVRSL, SLDR, FST-7 и кардио;
- текущий восьминедельный цикл, программы Антона и Сергея;
- локальное хранение, облачная синхронизация и PWA-кэш.

Проверка:

```bash
for file in *.js; do node --check "$file"; done
node --test tests/*.test.cjs
```

Рабочий адрес стабильной версии: `https://butafutsiy.github.io/unvrsl-fit/v1.1/`.
