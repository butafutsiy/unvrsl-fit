# UNVRSL FIT v1.1

Стабильная линия PWA с одной точкой входа и единым состоянием данных.

## Актуальные механики

- самочувствие до открытия тренировки: 0% при отличных показателях, снижение до 10% при отклонениях и ручная коррекция от −10% до +10%;
- плановый вес остаётся базой, рекомендация по прошлой тренировке и фактическому RPE применяется только по выбору;
- упражнения без веса обучаются на первой выполненной тренировке, после чего рабочая база используется во всём плане;
- история рабочих весов, веса тела и замеров с устойчивым удалением;
- нагрузка по 17 мышечным группам;
- локальное хранение, облачная синхронизация и безопасная миграция данных v1.0.

## Сборка

```bash
node --test tests/*.test.mjs
node scripts/build-v11.mjs
```

GitHub Pages публикует только `dist-v11`. Legacy-файлы остаются в истории репозитория, но не попадают в production-артефакт.
