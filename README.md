# UNVRSL FIT

Персональное PWA для тренировочного цикла: RPE/RIR, таймер отдыха, журнал, вес тела, индивидуальное оборудование и резервные копии JSON.

Данные тренировок хранятся локально на устройстве.

Питание: цели КБЖУ, офлайн-подбор меню на 3–5 приёмов, замены блюд,
порции, дневник съеденного по датам и список покупок. Без платных API.
КБЖУ блюд приблизительные, на основе усреднённых значений ингредиентов.
Подробности: [модуль питания](docs/meal-planner.md).
